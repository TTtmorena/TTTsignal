# TTTsignal — Usage Examples

This document lists the most common triggers and expected behavior of **TTTsignal**.

---

## 1. Basic Signal Requests

```
TTTsignal for CLAWD
give me a signal for this token
should I buy $TICKER?
signal for 0x...
TTTsignal analysis
full signal report for Surplus
```

**Expected Output:**  
Full standard signal report with BUY / HOLD / SELL + Confidence + Risk Level.

---

## 2. Momentum & Hot Tokens Scanner

```
hot Bankr tokens right now
volume spikes on Bankr
what’s pumping today
trending Bankr agents
show me strong momentum tokens
TTTsignal scanner
```

**Expected Output:**  
Top 5–10 tokens ranked by momentum + quick signal for each.

---

## 3. Risk Assessment

```
risk assessment for CLAWD
how risky is this token?
liquidity health check
is the liquidity healthy?
full risk analysis
```

**Expected Output:**  
Clear Risk Level (Low / Medium / High) + explanation based on liquidity, volume quality, and fee sustainability.

---

## 4. Comparison Mode

```
TTTsignal compare CLAWD vs Surplus
which one has better momentum: A or B?
compare these 3 tokens
side by side signal
```

**Expected Output:**  
Side-by-side table + declaration of which token currently has stronger momentum.

---

## 5. Entry / Exit Style Questions

```
good entry for this token?
where should I buy?
exit idea for $TICKER
suggested entry zone
invalidation level
```

**Expected Output:**  
Only given when data is strong enough. Always includes invalidation level and risk context.

---

## 6. General Rules of Behavior

- Always return the full standard signal format when possible
- Always include **Confidence** and **Risk Level**
- Always end with 1–3 Quick Actions
- If data is incomplete → clearly state “Limited data” and lower Confidence
- Never invent numbers or signals
- Stay factual, clear, and professional
